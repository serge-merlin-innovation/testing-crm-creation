### 2. The e2e session cap only shows up once enough specs exist

- Category: Automated checks
- Severity: high
- Evidence: Each ticket branch passed e2e alone. Combined, 6 specs log the admin in over the API, which pushed the storage-state session out at cap 5. The failures showed up as "redirected to /login" in unrelated admin specs.
- Suggested change: Done (playwright.config pins MAX_SESSIONS_PER_USER=50). Better long term: specs should reuse the banked admin storageState for API setup instead of opening new sessions.
- Target: apps/frontend/playwright.config.ts, apps/frontend/tests/e2e/identities.ts

- Severity: medium
