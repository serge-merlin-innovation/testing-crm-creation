# Postmortems

Reports written by the `retro-auto` skill at the end of every agent session that touches code, one file per session: `YYYY-MM-DD-HHMM-<main|worker>-<task-slug>.md`.

The reports are gitignored. This README is tracked so the folder exists in every clone: `retro-auto` only runs when `postmortem/` is present at the git root.
